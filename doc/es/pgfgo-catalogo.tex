\section{Catálogo de perfiles}
\label{sec:catalogo}

Los perfiles que trae \pgfgoname, cada uno con una muestra y con su definición, tal como está en |pgf-go-profiles.sty|. Se usan con |profile| (pág.~\pageref{subsec:perfiles}), y sus definiciones sirven de punto de partida para perfiles propios.

\subsection{default}

El estilo inicial del paquete: el que tienen el tablero y los jugadores antes de usar un perfil, y al que vuelven antes de aplicar cualquier otro.
\begin{codeexample}[width=4cm]
	\pgfgoset{profile = default}
	
	\begin{goban}[partial = A1:G3]
		\moves*[from = 1]{A:F 3}
		\stones[w]{A1:2}
		\stones[b]{B1:2}
		\stones[n]{C1:2}
		\stone[w, mark = circle]{D1}
		\mark[w, circle]{D2}
		\stone[b, mark = circle]{E1}
		\mark[b, circle]{E2}
		\stone[n, mark = circle]{F1}
		\mark[n, circle]{F2}
		\mark[w, t-square]{F1}
		\mark[b, t-circle]{F1}
		\mark[n, t-square]{F1}
	\end{goban}
\end{codeexample}

\subsubsection*{Jugadores}
Los colores |wainshade|, |wainwhite| y |wainblack| son los del perfil |wain|, más abajo.

	Declaramos todos los jugadores y comenzamos definiendo la apariencia del neutral.
	
	\begin{codeexample}[code only]
		\pgfgodefineplayer{pgfgo-neutral}{
			stone = {
				line = {
					true,
					color = black,
					width = 0.3pt,
					opacity = 1,
				},
				fill = {
					true,
					color = gray,
					opacity = 1,
				},
				radius = 0.17cm,
				scale = 1,
				shadow = {true, opacity = 0.5, offset = 1pt, angle = -45},
				shine = {true, angle = 45, color = wainshade}
			},
			move = {
				label = {
					color = black,
					format = arabic,
				}
			},
			mark = {
				line = {
					color = black,
					width = 1pt,
				},
				fill = {true, color = gray},
				label = {
					color = black,
					format = arabic
				}
			}
		}
	\end{codeexample}
	
	
	Algunas cosas como el grosor de linea, opacidades y dem\'as, deseo que se conserven en todas las piedras, as\'i que copio la plantilla del jugador neutral.
	
	\begin{codeexample}[code only]
		\pgfgodefineplayer[from = pgfgo-neutral]{pgfgo-white}{
			stone = {
				fill = {color = wainwhite},
				shine = {color = white}
			},
			move = {
				label = {
					color = black
				}
			},
			mark = {
				line 	= {color = black},
				label = {color = black}
			}
		}

		\pgfgodefineplayer[from = pgfgo-neutral]{pgfgo-black}{
			stone = {
				fill = {
					color = wainblack
				}
			},
			move = {
				label = {
					color = pgfgo
				}
			},
			mark = {
				line = {
					color = pgfgo,
				},
				label = {color = black}
			}
		}
	\end{codeexample}

\subsection{shell}
\label{subsec:perfilshell}

Un tablero de madera con piedras de pizarra y de concha, dibujados con imágenes (pág.~\pageref{subsec:piedrasimagen}). Las blancas usan cinco imágenes, cada una con sus vetas, y cada piedra está girada un poco, así que no se ven dos iguales; todas tienen una sombra difusa. Las imágenes vienen con \pgfgoname, en la carpeta |img|; los archivos que usa el perfil empiezan con |pgfgo-| y pueden usarse también en perfiles propios. Cada archivo se guarda una sola vez en el PDF, por más piedras que lo usen (pág.~\pageref{subsubsec:imagenespdf}). La sombra necesita pdf\LaTeX\ o Lua\LaTeX\ con salida PDF.

\begin{codeexample}[width=4cm]
	\pgfgoset{profile = shell}

	\begin{goban}[partial = A1:G3]
		\moves*[from = 1]{A:F 3}
		\stones[w]{A1:2}
		\stones[b]{B1:2}
		\stones[n]{C1:2}
		\stone[w, mark = circle]{D1}
		\mark[w, circle]{D2}
		\stone[b, mark = circle]{E1}
		\mark[b, circle]{E2}
		\stone[n, mark = circle]{F1}
		\mark[n, circle]{F2}
		\mark[w, t-square]{F1}
		\mark[b, t-circle]{F1}
		\mark[n, t-square]{F1}
	\end{goban}
\end{codeexample}

Como todos los perfiles, define también los jugadores |shell-neutral|, |shell-black| y |shell-white|: con |players profile = shell|, las piedras de pizarra y concha van sobre el tablero que se esté usando.

\begin{codeexample}[width=4cm]
	\pgfgoset{players profile = shell}

	\begin{goban}[partial = A1:G3]
		\stones[w]{A1:2, C3, E1}
		\stones[b]{B1:2, C2, D1, F2}
	\end{goban}
\end{codeexample}

\subsubsection*{Definición}

					image = {file = pgfgo-shadow.png}
				}
			}
		},
		black = {stone = {image = {file = pgfgo-shell-black.png}}},
		white = {
			stone = {
				image = {
					file = {pgfgo-shell-white-1.png, pgfgo-shell-white-2.png, pgfgo-shell-white-3.png,
						pgfgo-shell-white-4.png, pgfgo-shell-white-5.png},

				}
			}
		}
	}
\end{codeexample}

\subsection{yunzi}

Como |shell|, pero con piedras mates, sin vetas, como las \emph{yunzi} chinas: dos imágenes para las blancas, sin giro, porque la luz de cada imagen viene de un lado. Parte de |shell| (|from = shell|): solo cambia las imágenes de las piedras.

\begin{codeexample}[width=4cm]
	\pgfgoset{profile = yunzi}

	\begin{goban}[partial = A1:G3]
		\moves*[from = 1]{A:F 3}
		\stones[w]{A1:2}
		\stones[b]{B1:2}
		\stones[n]{C1:2}
		\stone[w, mark = circle]{D1}
		\mark[w, circle]{D2}
		\stone[b, mark = circle]{E1}
		\mark[b, circle]{E2}
		\stone[n, mark = circle]{F1}
		\mark[n, circle]{F2}
		\mark[w, t-square]{F1}
		\mark[b, t-circle]{F1}

\end{codeexample}
