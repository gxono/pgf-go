\section{Jugadores y perfiles}
\label{sec:jugadores}

Cada piedra, jugada y marca pertenece a uno de tres jugadores: el primero (|black|), el segundo (|white|) o el neutral (|neutral|). Su aspecto no está en cada comando sino en el jugador: el árbol de \emph{keys} de cada uno reúne las opciones de sus piedras, sus jugadas, sus marcas y su territorio, que en las secciones anteriores aparecen bajo |stone|, |move| y |mark|. Esta sección describe ese árbol completo y, después, los perfiles: cómo guardar con un nombre el estilo del tablero y de los jugadores, y cómo usarlo.

\subsection{Jugadores}

Cuando se desea cambiar una opción de tablero con |\pgfgoset|, puede hacerse directamente con |\pgfgoset{goban = {...}}|. Para los jugadores, la situación es algo distinta. Para ello, se cuenta con las siguientes \emph{keys}:

\begin{key}{/pgfgo/players = \meta{players options}}
	Permite ajustar las opciones de los jugadores. Por defecto, son tres: |neutral|, |black| y |white|. No hay que confundir jugadores con perfiles de piedras. Una vez cargado el perfil de una piedra, se puede realizar un cambio con estas \emph{keys}.
\end{key}

Las opciones de los jugadores pueden configurarse todas juntas con la \emph{key} |all|, o por separado. Los cambios realizados aquí no afectarán la definición de los perfiles. Es decir, si cargamos el perfil |pgfgo| y modificamos al jugador negro, esto no afectar\'a a la definici\'on de |pgfgo-black|, sino que a las opciones propias del jugador primero.

\begin{key}{/pgfgo/players/all = \meta{all player options}}
	Aplica las opciones a los tres jugadores.
\end{key}

\begin{key}{/pgfgo/players/neutral = \meta{neutral player options}}
	Opciones del jugador neutral (las piedras sin jugador).
\end{key}

\begin{key}{/pgfgo/players/black = \meta{first player options}}
	Opciones del primer jugador.
\end{key}

\begin{key}{/pgfgo/players/white = \meta{second player options}}
	Opciones del segundo jugador.

	\begin{codeexample}[width=4cm]
		\pgfgoset{players = {
			all = {stone = {line = {color = red}}},
			neutral = {stone = {fill = {color = yellow}}},
			black = {stone = {fill = {color = blue!60!black}}}}}

		\begin{goban}[3]
			\stones[b]{A1, B2}
			\stones[w]{C3}
			\stone{A3}
		\end{goban}
	\end{codeexample}
\end{key}

Para no escribir la ruta completa, hay cuatro comandos:

\begin{command}{\pgfgosetplayer\marg{player}\marg{player options}}
	Es lo mismo que |\pgfgoset{players = {<player> = {<player options>}}}|.
\end{command}

\begin{command}{\pgfgosetallplayers\marg{player options}}
	Aplica las opciones a los tres jugadores. Es lo mismo que |\pgfgoset{players = {all = {...}}}|.

	\begin{codeexample}[width=4cm]
		\pgfgosetallplayers{stone = {radius = 0.3cm}}
		\pgfgosetplayer{white}{stone = {fill = {color = orange}}}

		\begin{goban}[3]
			\stones[b]{A1, B2}
			\stones[w]{C3}
			\stone{A3}
		\end{goban}
	\end{codeexample}
\end{command}

\begin{command}{\pgfgocopyplayer\marg{target player}\marg{source player}}
	Copia las opciones actuales de |source player| en |target player|.

	\begin{codeexample}[width=3cm]
		\pgfgocopyplayer{neutral}{white}

		\begin{goban}[partial = A1:C3]
			\stone{B2} % Neutral, pero con el aspecto de las blancas.
			\stones[b]{A1,C3}
		\end{goban}
	\end{codeexample}
\end{command}

\begin{command}{\pgfgocopyplayers\marg{neutral source}\marg{black source}\marg{white source}}
	Copia, en este orden, |neutral source| en el jugador neutral, |black source| en el negro y |white source| en el blanco (con |\pgfgocopyplayer|). Como las copias se hacen una tras otra, no sirve para intercambiar jugadores.

	\begin{codeexample}[width=4cm]
		\pgfgocopyplayers{neutral}{white}{black}
		% No intercambia: las dos son blancas.

		\begin{goban}[3]
			\stones[b]{A1, B2}
			\stones[w]{C3}
		\end{goban}
	\end{codeexample}
\end{command}

\label{subsec:jugadores}Cada jugador tiene acceso al mismo árbol de \emph{keys}. Por esta razón, las siguientes, aunque mencionen |white|, aplican a todos los jugadores. Cada una de ellas se explica en la sección correspondiente al tipo de objeto, pero se ilustran brevemente ac\'a.

\begin{key}{/pgfgo/players/white/stone = \meta{stone options}}
	Controla las opciones de las piedras del segundo jugador.
\end{key}

\begin{key}{/pgfgo/players/white/stone/line = \meta{stone line options} (default true)}
	Controla las opciones de los bordes de las piedras del segundo jugador.
\end{key}

\begin{key}{/pgfgo/players/white/stone/line/true}
	Determina si aparece o no la frontera de una piedra.
	
	\begin{codeexample}[width=4cm]
		\pgfgoset{profile = pgfgosmooth}
		\pgfgoset{goban = {partial = A1:C3}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
		
		\pgfgoset{players = {white = {stone = {line = true}}}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/white/stone/line/false}	
\end{key}

\begin{key}{/pgfgo/players/white/stone/line/width = \meta{dimension}}
	Determina el grosor de la frontera de una piedra.
	
	\begin{codeexample}[width=4cm]
		\pgfgoset{profile = pgfgosmooth}
		\pgfgoset{goban = {partial = A1:C3}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
		
		\pgfgoset{players = {white = {stone = {line = {true, width = 1pt}}}}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/white/stone/line/color = \meta{color}}
	Determina el color de la frontera de una piedra.
	
	\begin{codeexample}[width=4cm]

		\end{goban}

			\stones[b]{B1,C2}

		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/white/stone/line/opacity = \meta{float}}
	Determina la opacidad de la frontera de una piedra.
	
	\begin{codeexample}[width=4cm]
		\pgfgoset{profile = pgfgosmooth}
		\pgfgoset{goban = {partial = A1:C3}}

\begin{key}{/pgfgo/players/white/stone/scale = \meta{float}}
	Controla la escala de la piedra, lo que afecta también a las marcas.

		\pgfgoset{profile = pgfgosmooth}

\begin{key}{/pgfgo/players/white/stone/shadow = \meta{stone shadow options} (default true)}
	La sombra de la piedra, dibujada debajo de ella. Por defecto tiene la silueta de la piedra: el círculo, o la forma de la imagen si la piedra es una imagen (|stone/image|). Con |image|, la sombra es una imagen propia. En los dos casos se corre |offset| hacia |angle| y se agranda |scale| veces.
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/true}
	Habilita la sombra en la piedra.
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/false}
	Desactiva la sombra en la piedra.
	\begin{codeexample}[width=4cm]
		\pgfgoset{profile = pgfgosmooth}
		\pgfgoset{goban = {partial = A1:C3}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
		
		\pgfgoset{players = {white = {stone = {shadow = false}}}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/angle = \meta{float} (initially 0)}
	Hacia dónde cae la sombra, en grados: con |0|, a la derecha; con |-45|, abajo a la derecha. No gira la forma de la sombra.
	\begin{codeexample}[width=4cm]
		\pgfgoset{profile = pgfgosmooth}
		\pgfgoset{goban = {partial = A1:C3}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
		
		\pgfgoset{players = {white = {stone = {shadow = {angle = 225}}}}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/offset = \meta{dimension} (initially 1pt)}
	Cuánto se corre la sombra respecto del centro de la piedra, en la dirección |angle|.
	\begin{codeexample}[width=4cm]
		\pgfgoset{profile = pgfgosmooth}
		\pgfgoset{goban = {partial = A1:C3}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
		
		\pgfgoset{players = {white = {stone = {shadow = {offset = 0.125cm}}}}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/opacity = \meta{float} (initially 0.5)}
	Controla la opacidad de la sombra (también la de la sombra con imagen).
	\begin{codeexample}[width=4cm]
		\pgfgoset{profile = pgfgosmooth}
		\pgfgoset{goban = {partial = A1:C3}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
		
		\pgfgoset{players = {white = {stone = {shadow = {offset = 0.125cm, opacity = 0.1}}}}}
		
		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/color = \meta{color} (initially black)}
	El color de la sombra. Una sombra con imagen tiene sus propios colores, salvo con |image/silhouette|.

	\begin{codeexample}[width=4cm]
		\pgfgoset{profile = pgfgosmooth}
		\pgfgoset{goban = {partial = A1:C3}}
		\pgfgoset{players = {white = {stone = {shadow = {color = blue, offset = 0.1cm}}}}}

		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/scale = \meta{float} (initially 1)}
	Agranda (o achica) la sombra respecto de la piedra. Una sombra más grande que la piedra la hace parecer más alta. También agranda la sombra con imagen.

	\begin{codeexample}[width=4cm]
		\pgfgoset{goban = {partial = A1:C3, scale = 2}}

		\begin{goban}
			\stone[b, shadow = {true, angle = -45}]{A1}
			\stone[b, shadow = {true, angle = -45,
				scale = 1.3}]{C2}
			\stone[w, shadow = {true, offset = 0pt,
				scale = 1.3, color = red}]{A3}
		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/image = \meta{options}}
	Una sombra propia: una imagen con transparencia (PNG o PDF), centrada en la piedra y dibujada tal cual en lugar de la silueta, por ejemplo una sombra difusa. Se corre y se agranda como la silueta (|angle|, |offset|, |scale|) y usa |opacity|, pero no |color|. No gira con la imagen de la piedra (|stone/image/rotate|), así que cae siempre hacia el mismo lado. Cada archivo se guarda una sola vez en el PDF.

	\begin{codeexample}[width=4cm]
		\pgfgoset{goban = {partial = A1:C3, scale = 2}}
		\pgfgoset{stone = {shadow = {true, angle = -45,
			offset = 1.5pt, opacity = 0.8,
			image = {file = pgfgo-shadow.png, width = 13pt}}}}

		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/image/file = \meta{file}}
	El archivo de la imagen. Se busca como con |\includegraphics|.
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/image/width = \meta{dimension} (initially el diámetro de la piedra)}
	El ancho de la imagen; el alto mantiene la proporción.
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/image/rotate = \meta{ángulo} (initially 0)}
	Gira la imagen de la sombra, igual en todas las piedras.
\end{key}

\begin{key}{/pgfgo/players/white/stone/shadow/image/silhouette = \meta{boolean} (default true, initially false)}
	Usa solo la forma de la imagen (su transparencia), pintada con |shadow/color|, en lugar de la imagen tal cual. Necesita pdf\LaTeX\ o Lua\LaTeX\ con salida PDF; con otros motores la sombra no se dibuja y aparece un aviso.

	\begin{codeexample}[width=4cm]
		\pgfgoset{goban = {partial = A1:C3, scale = 2}}
		\pgfgoset{stone = {shadow = {true, angle = -45,
			offset = 2pt, color = blue,
			image = {file = star.pdf, width = 16pt,
				rotate = 18, silhouette}}}}

		\begin{goban}
			\stones[b]{B1,C2}
			\stone[w]{A3}
		\end{goban}
	\end{codeexample}
\end{key}

\subsection{Perfiles}
\label{subsec:perfiles}

Los perfiles son equivalentes a los estilos de \tikzname. En resumen, permiten guardar una configuración de tablero y piedras con un nombre y llamarla cuando se desee.

\begin{command}{\pgfgodefinegoban\opt{\oarg{options}}\marg{goban name}\marg{goban options}}
	Permite asignar un nombre a un grupo de opciones de goban. Tiene dos posibles opciones no obligatorias.
	
	\begin{key}{/pgfgo/profiles/goban/from = \meta{goban name}}
		Permite definir un goban a partir de una copia de otro.
		\begin{codeexample}[code only]
			\pgfgodefinegoban[from = gobanA]{gobanB}{...}
		\end{codeexample}
		
		Es posible copiarse a sí mismo para añadir opciones, aunque no es la mejor alternativa.
		\begin{codeexample}[code only]
			\pgfgodefinegoban[from = gobanB]{gobanB}{...}
		\end{codeexample}
	\end{key}
	
	\begin{key}{/pgfgo/profiles/goban/append}
		Permite ampliar las opciones de un goban.
		\begin{codeexample}[code only]
			\pgfgodefinegoban[append]{gobanB}{...}
		\end{codeexample}
		Es equivalente a:
		\begin{codeexample}[code only]
			\pgfgodefinegoban[from = gobanB]{gobanB}{...}
		\end{codeexample}
	\end{key}
\end{command}

\begin{command}{\pgfgodefineplayer\opt{\oarg{options}}\marg{player name}\marg{player options}}
	Permite asignar un nombre a un grupo de opciones de piedras. Sus opciones son equivalentes a las de |\pgfgodefinegoban|.

	\begin{key}{/pgfgo/profiles/player/from = \meta{player name}}
		Define el jugador a partir de una copia de otro.
	\end{key}

	\begin{key}{/pgfgo/profiles/player/append}
		Amplía las opciones de un jugador ya definido. Es lo mismo que |from = |\meta{player name} con su propio nombre.
	\end{key}
\end{command}

\begin{key}{/pgfgo/profile = \meta{name}}
	Aplica el perfil |name|: el goban |name| y los jugadores |name-neutral|, |name-black| y |name-white|. Sirve en |\pgfgoset|, en las opciones de un |goban| y en las de una vista (p.~\pageref{subsec:vistas}).

	Antes de aplicarlo, el tablero y los jugadores vuelven al estilo inicial (el del perfil |default|): así un perfil no hereda lo que no define, y una sombra o una imagen puesta antes se pierde. Lo que no es estilo queda como estaba: el tamaño, |partial|, |scale|, dónde van las coordenadas y cuáles son, |hoshi/at|, las capturas y las notas. Lo que va después del perfil se suma a él.

	\begin{codeexample}[width=3cm]
		\pgfgoset{stone = {shadow}}
		\begin{goban}[3, profile = default]
			\stones[b]{A1, B2}
			\stones[w]{C3}
		\end{goban}
	\end{codeexample}

	Es necesario que existan el goban |name| y los jugadores |name-neutral|, |name-black| y |name-white|. Por ejemplo, |profile = pgfgo| funciona porque existe un goban llamado |pgfgo|, y jugadores llamados |pgfgo-neutral|, |pgfgo-black| y |pgfgo-white|.
\end{key}

\begin{key}{/pgfgo/goban profile = \meta{goban name}}
	Aplica solo el goban |goban name|, después de volver el tablero al estilo inicial.
\end{key}

\begin{key}{/pgfgo/players profile = \meta{name}}
	Aplica solo los jugadores |name-neutral|, |name-black| y |name-white|, cada uno después de volver al estilo inicial.

	\begin{codeexample}[]
		\begin{goban}[3, goban profile = pgfgo]
			\stones[b]{A1, B2}
			\stones[w]{C3}
		\end{goban}

		\begin{goban}[3, players profile = pgfgo]
			\stones[b]{A1, B2}
			\stones[w]{C3}
		\end{goban}
	\end{codeexample}
\end{key}

\begin{key}{/pgfgo/players/black/profile = \meta{player name}}
	Aplica el jugador |player name| a uno de los jugadores (|neutral|, |black| o |white|), después de volverlo al estilo inicial. Con |all|, el mismo a los tres.
	\begin{codeexample}[code only]
		\pgfgoset{goban profile = pgfgo, players = {black = {profile = wain-black}}}
	\end{codeexample}
\end{key}

\begin{codeexample}[width=3cm]
	\pgfgodefinegoban{example}{background = {fill = {color = blue!05}}}
	\pgfgodefineplayer[from = default-neutral]{example-neutral}
	{stone = {
			fill = {color = gray},
			line = {color = magenta!20!black}}
	}
	
	\pgfgodefineplayer[from = example-neutral]{example-white}
	{stone = {fill = {color = yellow}}}
	
	\pgfgodefineplayer[from = example-neutral]{example-black}
	{stone = {fill = {color = blue}}}
	
	\pgfgoset{profile = example}
	
	\begin{goban}[partial = A1:C3]
		\moves{A1:3}
		\stones[b]{B1,B3,C2}
		\stones[w]{C1,C3}
		\stone{B2}
	\end{goban}
\end{codeexample}

\begin{command}{\pgfgodefineprofile\opt{\oarg{options}}\marg{name}\marg{profile options}}
	Define de una vez un perfil completo para |profile|: el goban |name| y los jugadores |name-neutral|, |name-black| y |name-white|. Es lo mismo que el ejemplo de arriba, en un solo comando.

	\begin{codeexample}[width=3cm]
		\pgfgodefineprofile[from = default]{ejemplo2}{
			goban = {background = {fill = {color = blue!05}}},
			all = {stone = {line = {color = magenta!20!black}}},
			white = {stone = {fill = {color = yellow}}},
			black = {stone = {fill = {color = blue}}}}

		\pgfgoset{profile = ejemplo2}

		\begin{goban}[partial = A1:C3]
			\moves{A1:3}
			\stones[b]{B1,B3,C2}
			\stones[w]{C1,C3}
			\stone{B2}
		\end{goban}
	\end{codeexample}

	\begin{key}{/pgfgo/profiles/profile/goban = \meta{goban options}}
		Las opciones del goban.
	\end{key}

	\begin{key}{/pgfgo/profiles/profile/all = \meta{player options}}
		Opciones de los tres jugadores. Van antes de las de cada uno.
	\end{key}

	\begin{key}{/pgfgo/profiles/profile/neutral = \meta{player options}}
		Opciones del jugador neutral.
	\end{key}

	\begin{key}{/pgfgo/profiles/profile/black = \meta{player options}}
		Opciones del jugador negro.
	\end{key}

	\begin{key}{/pgfgo/profiles/profile/white = \meta{player options}}
		Opciones del jugador blanco.
	\end{key}

	\begin{key}{/pgfgo/profiles/profile/from = \meta{profile name}}
		Opción del comando: cada parte empieza con la del perfil \meta{profile name} (el goban \meta{profile name}, el jugador \meta{profile name}|-neutral|, etc.).
	\end{key}
\end{command}
